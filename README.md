# fitmyface-media

Public download links for **finished, approved** FitMyFace social videos, so the Buffer scheduler can fetch them
(Buffer needs a public file URL; the main repo is private). Every file here is already meant to be public on
TikTok, Instagram and YouTube. Faces are fictional and AI-made; looks are AI previews.

Rules: only videos that passed independent review and are not held (see `docs/MARKETING_STATUS.md` in the main repo).
No raw photos, no user photos, no credentials, nothing else.

`legal/` holds the public privacy policy and data-deletion instructions for the FitMyFace Studio publishing tool (required by the YouTube, Meta and TikTok developer programs). No personal data.
